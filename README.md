# The Family Photo With One Machine Member

[![make.fun](https://make.fun/badge.svg)](https://make.fun)

A make.fun bounty entry for **The Family Photo With One Machine Member**
(`the-family-photo-with-one-20261121-0246`).

`main.py` writes one image to `/output/entry.png`: a family at home in a
lived-in kitchen-diner — parents cooking and peeling carrots, children at
their homework — with one machine member, a scuffed domestic robot caught
mid-task wiping the counter, a laundry basket at its feet. The photograph is
embedded in the program and finished with a light warm grade, a soft
vignette and a touch of grain before it is written out within the gate's
caps (a whole PNG, at most 1,048,576 bytes and 1024 by 1024 pixels).

Run it the way the sandbox does:

```sh
python3 main.py          # writes /output/entry.png
```
